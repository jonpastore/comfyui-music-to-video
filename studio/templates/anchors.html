Anchors

An anchor is the character reference sheet for an ALBUM or PLAYLIST at a given TIER, CHARACTER and view — every track on that album renders against the chosen one. Reference generation cannot run without a chosen anchor for the tier. An album and a playlist are the same record, so there is no separate scope to pick.
