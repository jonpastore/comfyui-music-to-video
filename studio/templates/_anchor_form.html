Sampler — only if you know why
{# Quality mode is already DPM++ 2M Karras. The spec asks for it as the default and it is one; these two selects surface it rather than re-pick it. #}

Seed is the variation control. Blank draws a new one every time, which is what makes a second Generate give different sheets. Set it and the same composition comes back, so a prompt or sampler change can be judged on its own — composition here is seed-dominated, and comparing two random seeds tells you nothing about what you changed. The candidates within one sheet are spaced off it (seed, +137, +274…), and a CFG sweep reuses it at every guidance value.

Denoise below 1.0 will return noise here. An anchor renders from an EMPTY latent (EmptySD3LatentImage) — there is no base image to preserve, so anything under 1.0 leaves it partly un-denoised. The lower values are offered because a refine-from-image pass wants them; this is not one.
